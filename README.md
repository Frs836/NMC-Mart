# NMC Mart - Retail POS System

A mobile-first, offline-ready retail Point of Sale (POS) application built for minimarkets with AI assistance, real-time inventory management, multi-branch support, and Supabase cloud sync.

## Features
- **Cashier POS**: Quick product search, barcode scanning, cart management, and shift reporting.
- **Inventory & Stock Opname**: Real-time stock tracking, rack transfers, purchase orders, and stock opname audits.
- **AI Assistant**: Intelligent inventory insights powered by Gemini AI.
- **Multi-Branch & Cloud Sync**: Data persistence using local IndexedDB (Dexie) with automatic Supabase synchronization.
- **Finance & Cashflow**: Track income, expenses, and store performance reports.

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Lucide Icons, Recharts
- **State & Storage**: Zustand, Dexie.js (IndexedDB), Supabase Client
- **Server**: Express.js with Node.js
